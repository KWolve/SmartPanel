松手即导入视频

多屏拼接 · 视频切块

导入视频 → 摆绿框 → 导出分段 → 分发到屏
使用说明 / 快捷键
① 导入视频：选文件或直接把视频拖到页面上（已导入过的点一下名字即可再次使用，不用重传）。
② 摆框（每屏一个窗口）：视频画面固定不动，每屏的绿框可以各自独立拖动 （拖到哪台屏就只动那一个框），拖空白处 / 按住 Alt / 勾「拖整组」= 整组一起动， 滚轮/缩放条 = 改窗口大小（各屏边长始终一致 → 缩放一致）。
屏缝：物理拼缝补偿 —— 相邻两屏之间可以留出 N px 的「缝」，缝里的源画面 不导出（丢弃），这样两台屏拼起来画面才是连续的；缝 = 0（默认）= 无缝，与旧版完全一致。
每个窗口都被钳制在视频内 → 不会出现黑边。绿框里显示什么，导出的那段就是什么； 框外 + 缝内那层压暗（强度可用顶栏「压暗」滑条调，默认 50%）= 会丢弃的部分。
③ 导出分段：出 seg_1..N.mp4（每段 480×480、参数完全一致、首帧 IDR）+ wall.json； 再到右侧「分发到屏幕」。
快捷键（点一下画面后生效）：方向键 微调 2px（按住 Shift = 20px； 编码要求裁剪矩形偶数对齐，所以最小步长是 2px）、 +/- 缩放、M 铺满、C 居中、 [/] 前后一帧。
方向键 = 只动当前选中的那一屏（点一下画面里的框即选中；按 Alt+方向键 = 整组）。

① 导入视频（可多个 → 形成一个组的轮播队列）

支持 mp4 / mov / mkv 等（直接拖到页面上也行）
点视频名 = 加入队列并选中它摆框（已在队列里的再点一次 = 切成当前编辑）

② 组的视频队列（顺序 = 轮播顺序；每个 = 一个 clip，长短不限）

改名（= cN 子目录名，只允许字母/数字/_.-）/ 上下移 / 删除；点一行 = 选中它摆框
队列为空：先在①里导入并点一下视频名
预览时间 - s

③ 每屏窗口 = 裁剪窗口（每屏可独立拖动 / 滚轮缩放）

分割数量 拖框=只动那一屏（拖空白=整组）
屏缝 px 相邻两屏之间不显示的区域（物理拼缝；0 = 无缝）
缩放 -
外框精确输入（源像素） x y w （按"无缝 N 等分"重排；w 必须 = N×h）
点一下某一屏 = 选中它（方向键 2px / Shift 20px 只动这一屏； 按住 Alt 或勾「拖整组」= 整组一起动）；选中屏在画面里是实线加粗框

⑥ 分发到屏幕（整组递归推送：含 playlist.json）

用④里的组名 + 当前选中的已导出分组
